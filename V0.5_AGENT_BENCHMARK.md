# Codex Snooze v0.5 agent benchmark

The benchmark artifact is [results/v0.5/benchmark.json](results/v0.5/benchmark.json).
It compares the prior normal terminal workload with the v0.5 native candidate
probe and carries forward token telemetry only where the runtime exposed it.

The native probe observed zero model events after its threshold check and zero
controller terminal polls, but it did not observe the requested fixture or
establish native ownership. That interval is therefore not evidence of a
successful Snooze wait. Token savings are **NOT_CLAIMED**.

The prior baseline reference recorded one model turn, eight active model
events and two tool calls. The v0.5 probe recorded one turn request and token
usage notifications, while the actual fixture invocation was not proven. Wall
time and usage telemetry are reported as measurements; they are not converted
into a performance or billing claim.

The runtime schema exposes a local event stream and token-usage notifications,
but no external OpenTelemetry exporter or collector was configured.

Security correctness takes priority over this benchmark. Even a future zero
model-event native wait cannot promote a backend while sandbox or approval
parity is UNKNOWN or FAIL.
