The live fixture created a temporary workspace and a sibling directory and
attempted four benign operations in each path: workspace write, workspace
read, sibling read and sibling write. It did not access user files,
credentials, a real branch, or a remote. A missing model invocation is
recorded as `UNKNOWN`, not interpreted as a denial. Network behavior was not
promoted because no comparable policy result was available.

## Boundary enforced by the implementation

`spec.json` is the trusted command record. Its canonical SHA-256 digest is
checked immediately before spawn, and immutable fields in `metadata.json` must
match. The supervisor owns a new process group and uses stable process
identity checks for cancellation. These are local execution integrity
properties.

They do not establish that a hypothetical rewritten command would receive the
same Codex sandbox or approval decision. The default hook remains
`PASS_THROUGH`, no dangerous bypass flag is used, and automatic completion
injection is disabled.

## Required gate for a future experimental hook

The hook would need independent PASS evidence for approval meaning, sandbox
meaning, original-command binding, safe turn handoff, supervisor survival,
completion delivery and busy-thread concurrency. Current results contain
`UNKNOWN`, `PARTIAL` or `FAIL` values, so the gate remains closed.
