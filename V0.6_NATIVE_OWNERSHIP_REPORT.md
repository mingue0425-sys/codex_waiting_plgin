# Codex Snooze v0.6 native ownership proof

v0.6 tests whether Snooze can observe an existing normal Codex terminal
execution and receive background ownership without starting the command again.
The baseline is `ff472c5fbbf8629bb414b61018fe5cfc22b81276` on
`v0.5-security-handoff`.

## Result

| Candidate | Normal command item | Fixture side effect | Background record | Process correlation | Result |
|---|---|---:|---:|---|---|
| `THREAD_NATIVE_TERMINAL` | observed | no | empty | UNKNOWN | **UNKNOWN** |
| `SANDBOX_DESCENDANT_SUPERVISOR` | observed | no | empty | UNKNOWN | **UNKNOWN** |
| `CONTROLLER_COMMAND_EXEC` | reference only | sibling write in v0.4 | not a candidate | not applicable | **FAIL** |

The installed runtime emitted normal `commandExecution` item events with a
`processId`, `cwd`, command text and exit code. The command text was the normal
runtime shell form, for example `/bin/zsh -lc 'python3 fixture.py'`. That is
recorded as a runtime wrapper; it is not treated as exact semantic command
integrity evidence.

The experimental `thread/backgroundTerminals/list` response was empty before,
at the ten-second observation point and after the turn. The disposable fixture
files were not visible in the controller's temporary workspace, so no
itemId/processId/cwd/command/process-start identity correlation was possible.
The controller used no `command/exec`, `process/spawn` or `thread/shellCommand`
request for either candidate.

## Correlation rule

The v0.6 gate requires matching item identity, process identity, canonical
command, cwd and a bounded OS identity (`osPid` or a matching process start
identity). A matching command string by itself is insufficient. Missing
identity remains UNKNOWN; mutation is FAIL.

The detailed live evidence is in
[results/v0.6/process-correlation.json](results/v0.6/process-correlation.json)
and the strict evaluator is
[snooze_controller/v06_ownership.py](snooze_controller/v06_ownership.py).

## Ownership consequence

No ownership transfer was attempted after the required correlation evidence
was absent. This avoids interrupting or re-executing an execution whose
authority and process identity were not established. The durable local CAS
ledger still passes its 100-iteration single-owner race, but that is an
ownership-state invariant and does not prove native process delivery.
