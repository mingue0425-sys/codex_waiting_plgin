Backend A is the preferred candidate because it would preserve the original
normal terminal command and its tool approval path. The installed runtime
exposes relevant item events and an experimental background-terminal list, but
the live fixture did not establish a process handle or shared filesystem
identity.

Backend B is a fallback research path. The host-only detached process test
cannot establish Codex sandbox inheritance, and the normal-thread descendant
fixture was not locally observable.

Backend C remains the v0.4 failure reference. It is never selected by the
v0.5 selector, even if its local execution and command hash checks pass.

The selector returns `CLI_RESUME_FALLBACK` whenever the required security or
ownership evidence is UNKNOWN, PARTIAL or FAIL. No automatic v0.5 features are
enabled.
